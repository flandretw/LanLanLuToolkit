# 蘭蘭露工具箱

[English](README.md) | [臺灣正體中文](README-zh_TW.md)

> **注意事項**  
> 本專案使用 **Gemini 氛圍編碼 (Vibe Coding)** 撰寫，由 AI 魔法與過量的數位薯條驅動。**使用請注意**！如果您發現 UI 開始跳舞或程式碼看起來像某種神秘咒語，別擔心——那只是「氛圍」到位了。

「蘭蘭露！你的 Windows 體驗已經被注入了瘋狂的能量！」

## 這是什麼專案？

蘭蘭露工具箱是一款基於 WinUI 3 打造的輕量免安裝系統維護與外設檢測工具。融合了現代 Windows 介面的流暢動效與 2000 年代經典迷因的活力，它不需要安裝程序，也不會在系統登錄檔中留下任何殘渣，隨開即用，放進隨身碟就能帶著走。

## 特色功能

* **即時硬體監控（實驗性）**  
  提供 CPU、GPU、記憶體與磁碟的基本負載、時脈、VRAM 與溫度概覽。適合在不想額外開啟工作管理員時隨手確認系統狀態。目前本功能處於實驗階段，若需嚴謹的效能診斷仍建議使用 Windows 原生工作管理員。

* **鍵鼠外設診斷**  
  專為電競玩家與鍵鼠愛好者打造的即時檢測工具，支援 60 fps 視窗自適應縮放與按鍵音效回饋。
  * 全能鍵盤檢測：支援 104 全尺寸、87 鍵 TKL 與 61 鍵精簡配置即時切換，具備全鍵無衝突紀錄、虛擬鍵碼辨識與按鍵觸發抖動警示，方便驗證二手或新鍵盤的無衝突表現。
  * 滑鼠極限診斷：提供微動開關點擊計數、即時回報率精密計算、滾輪刻度測試與即時軌跡畫布，並可自訂防抖閾值以判別微動開關雙擊故障，快速檢驗電競滑鼠是否穩定運作於 1000 Hz 以上。

* **當機藍畫面分析**  
  免安裝肥大的除錯套件，直接在簡潔介面中排查系統崩潰原因。
  * Minidump 記憶體傾印分析：自動讀取系統 Minidump 目錄，解析 BugCheck 代碼、崩潰時間與引發藍畫面的罪魁禍首驅動程式檔名 (`.sys`)。
  * 重大事件篩選：整合 Windows 事件檢視器即時提取近期嚴重系統錯誤，在無預警重啟或藍畫面時迅速鎖定問題驅動或衝突元件。

* **系統修復**  
  免開命令提示字元，一鍵呼叫 DISM 與 SFC 系統核心修復工具，有效解決系統檔案損毀或更新卡頓異常。
  * DISM 映像修復：支援 CheckHealth、ScanHealth 與線上 RestoreHealth 映像復原。
  * SFC 系統檔案修復：一鍵執行 `SFC /scannow`，修復受損的核心系統組件。
  * 元件庫清理：自動清理冗餘更新快取與 WinSxS 元件庫以節省空間。

* **極速雜湊碼比對**  
  多執行緒高速檔案指紋計算器，支援 MD5、SHA-1、SHA-256、SHA-384、SHA-512、SHA-3 等演算法。支援檔案直接拖曳計算與目標值快速比對，方便下載系統映像檔或安裝套件時迅速驗證資料完整性。

* **檔案關聯管家**  
  集中檢視文字、壓縮檔、影音媒體等多種常見格式的系統預設關聯程式。當副檔名開啟方式被第三方軟體竄改或圖示異常時，可迅速檢視並恢復預設開啟工具。

* **現代化介面**  
  採用 WinUI 3 與雲母特效，動態儀表板與卡片佈局均會自動適應視窗縮放，保持視覺細膩流暢。

* **佈景主題切換**  
  完整支援淺色與深色模式切換，主題感知介面確保在任何環境下皆有良好的對比度與閱讀體驗。

* **免安裝純綠色架構**  
  100% 免安裝設計，解壓縮即可執行。不向登錄檔寫入多餘垃圾，不會污染作業系統。

* **多語言支援**  
  完整支援英文與臺灣正體中文介面切換，所有功能與設定文字均經在地化潤飾。

## 安裝與啟動

1. 前往 [Releases](https://github.com/flandretw/lanlanlu-toolkit/releases) 頁面下載最新的 `.zip` 檔案。
2. 解壓縮到任何您想放的地方——桌面、隨身碟，或是您的個人資料夾。
3. 執行 `lanlanlu-toolkit.exe`，開始體驗！

## 從原始碼編譯

如果您擁有 **Visual Studio 2026**（須包含 Windows SDK 10.0.19041.0）與冒險精神，可以嘗試自己封裝：

```powershell
# 將程式封裝進免安裝資料夾（預設為 x64）
.\scripts\Build-Portable.ps1

# 指定不同架構 (x64, arm64)
.\scripts\Build-Portable.ps1 -Arch arm64
```
