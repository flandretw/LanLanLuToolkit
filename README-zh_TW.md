# 蘭蘭露工具箱 (LanLanLu Toolkit)

「藍藍路！你的 WinUI 3 體驗已經被注入了瘋狂的能量！🤡🍟」

來自網路深淵最繽紛的瘋狂⸺**蘭蘭露工具箱**！這是一個基於 **WinUI 3** 的超精美、便攜式工具箱，致力於為您提供那些您可能不知道自己需要、但一旦用了就回不去的強大工具！

> ⚠️ **注意事項**
> 本專案使用 **Gemini 氛圍編碼 (Vibe Coding)** 撰寫，由 AI 魔法與過量的數位薯條驅動。**使用請注意**！如果您發現 UI 開始跳舞或程式碼看起來像某種神秘咒語，別擔心⸺那只是「氛圍」到位了 🪄

## 🌀 這是什麼瘋狂的傑作？

您是否厭倦了那些死氣沉沉、還要安裝一堆垃圾才能啟動的工具？您是否渴望在現代 Windows 介面中感受到 2000 年代經典迷因的原始能量？

**蘭蘭露工具箱**就是為此而生！建立在尖端的 **WinUI 3** 框架之上，它為您帶來最頂級、且能裝進口袋（或隨身碟）的便攜體驗。免安裝、不留登錄檔殘渣，只有純粹的工具魔法。

## 🛠️ 安裝與啟動 (Setup)

1. 前往 [Releases](https://github.com/flandretw/lanlanlu-toolkit/releases) 頁面下載最新的 `.zip` 檔案。
2. 解壓縮到任何您想放的地方⸺桌面、隨身碟，或是您的祕密資料夾。
3. 執行 `lanlanlu-toolkit.exe`，讓瘋狂開始吧！

## 🏗️ 從原始碼編譯 (法師限定)

如果您擁有 Visual Studio 2022 與冒險精神，可以嘗試自己打包：

```powershell
# 將魔法打包進便攜資料夾 (預設為 x64)
.\scripts\Build-Portable.ps1

# 指定不同維度的架構 (x64, x86, arm64)
.\scripts\Build-Portable.ps1 -Arch arm64
```
