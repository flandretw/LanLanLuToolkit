## 🌀 這是什麼瘋狂的傑作？

您是否厭倦了那些死氣沉沉、還要安裝一堆垃圾才能啟動的工具？您是否渴望在現代 Windows 介面中感受到 2000 年代經典迷因的原始能量？

**蘭蘭露工具箱**就是為此而生！建立在尖端的 **WinUI 3** 框架之上，它為您帶來最頂級、且能裝進口袋或隨身碟的免安裝體驗。免安裝、不留登錄檔殘渣，只有純粹的工具魔法。

## 🔥 超狂魔法特性

* 📊 **即時硬體監控（實驗性）**
  想要看硬體狀態？我們試著做了一個！雖然目前這項功能前景未明、操作上還有些粗糙，且效能開銷與流暢度遠不如 Windows 內建的工作管理員（認真排查效能還是建議開工作管理員 🤡），但依然提供了 **CPU、GPU、RAM 與磁碟** 的基本負載、時脈、VRAM 與溫度概覽。
  > 💡 **實用場景**：在不想開工作管理員時隨手瞄一眼硬體概要，或是當作硬體輪詢的實驗展示。

* ⌨️🖱️ **神速鍵鼠外設診斷**
  為電競玩家與鍵鼠發燒友量身打造的全方位檢測神器，支援 60 fps 視窗自適應縮放與按鍵音效回饋！
  * **全能鍵盤檢測**：支援 104 全尺寸、87 鍵 TKL 與 61 鍵精簡配置即時切換，具備 NKRO 全鍵無衝突紀錄、虛擬鍵碼辨識與按鍵觸發間隔連發/抖動警示。
  * **滑鼠極限診斷**：微動開關點擊計數、即時回報率精密計算器、滾輪刻度測試、微動開關連點故障判定（可自訂防抖閾值，揪出雙擊故障）與即時軌跡畫布。
  > 💡 **實用場景**：驗證新買或二手鍵盤是否全鍵無衝突、老舊滑鼠是否出現「點一下變點兩下」的連點故障、實測電競滑鼠是否真正穩定運作在 1000 Hz 以上。

* 💥 **當機藍畫面終結者**
  免安裝幾十 GB 的肥大除錯工具，直接在優雅的介面中洞悉系統崩潰的真相！
  * **Minidump 記憶體傾印分析**：自動讀取 `C:\Windows\Minidump`，解析 BugCheck 代碼、崩潰時間與引發藍畫面的罪魁禍首驅動程式檔名 (`.sys`)。
  * **重大事件篩選**：整合 Windows 事件檢視器，即時提取近期 Critical 嚴重系統錯誤。
  > 💡 **實用場景**：電腦突發藍畫面當機或無預警重新啟動時，秒速找出是哪張顯示卡驅動程式、防毒軟體或硬體衝突導致當機。

* 🛠️ **神級系統修復**
  Windows 又在耍脾氣？轟！一鍵發動 **DISM 與 SFC** 修復咒語。
  * **DISM 映像修復**：支援 CheckHealth、ScanHealth 與線上 RestoreHealth 映像復原。
  * **SFC 系統檔案修復**：一鍵執行 `SFC /scannow`，在混沌吞噬一切之前拯救損毀的 Windows 核心系統檔案。
  * **元件庫清理**：自動清理冗餘更新快取與 WinSxS 元件庫。
  > 💡 **實用場景**：Windows Update 更新卡住報錯、系統核心檔案損毀時，免開命令提示字元，一鍵依序自動修復。

* 🔐 **極速雜湊碼比對**
  多執行緒高速檔案指紋計算器，支援 **MD5、SHA-1、SHA-256、SHA-384、SHA-512、SHA-3** 等多種演算法。
  * 支援直接將檔案拖曳至視窗內即刻計算。
  * 內建目標雜湊碼比對欄位，自動驗證一致性並給予顏色辨識。
  > 💡 **實用場景**：下載系統 ISO 映像檔或軟體安裝包時，秒速驗證檔案是否完整、是否遭中途竄改或損毀。

* 📂 **檔案關聯管家**
  集中檢視文字檔、壓縮檔、影音媒體等多種常見格式的系統關聯程式，快速修復異常關聯。
  > 💡 **實用場景**：副檔名開啟方式被流氓軟體劫持或圖示錯亂時，快速檢視並恢復預設開啟工具。

* 🌀 **現代化瘋狂 (WinUI 3)**
  流暢的動畫、**雲母 (Mica) 特效**，以及像剛炸好撒鹽的薯條一樣新鮮的佈局！動態 Hero 儀表板與所有卡片會像魔法一樣自動適應您的視窗大小。

* 🎨 **佈景主題降維打擊**
  整個應用程式會瞬間適應您的氛圍！無論您身處淺色還是深色維度，我們的主題感知 UI 都能確保完美的對比度與可讀性。

* 📦 **拒絕束縛免安裝版**
  我們跟您一樣討厭安裝程式。本工具箱 **100% 免安裝**。下載、解壓縮、點擊執行！它不會在您的系統留下任何登錄檔痕跡，保持您的 Windows 乾淨溜溜。

* 🌐 **全球火星化支援**
  完全為世界而在地化！無論您說的是英文，還是聖潔的臺灣正體中文，這場瘋狂都被完美地翻譯了。

## 🛠️ 安裝與啟動

1. 前往 [Releases](https://github.com/flandretw/lanlanlu-toolkit/releases) 頁面下載最新的 `.zip` 檔案。
2. 解壓縮到任何您想放的地方——桌面、隨身碟，或是您的祕密資料夾。
3. 執行 `lanlanlu-toolkit.exe`，讓瘋狂開始吧！

## 🏗️ 從原始碼編譯（法師限定）

如果您擁有 **Visual Studio 2026**（須包含 Windows SDK 10.0.19041.0）與冒險精神，可以嘗試自己封裝：

```powershell
# 將魔法封裝進免安裝資料夾（預設為 x64）
.\scripts\Build-Portable.ps1

# 指定不同維度的架構 (x64, arm64)
.\scripts\Build-Portable.ps1 -Arch arm64
```
